# KI-Zentrale – Downloads

Hier gibt es die fertigen Installationsdateien der **KI-Zentrale**, einer persönlichen KI-Steuerzentrale für Windows.

## Installieren

1. Unter **[Releases](../../releases/latest)** die Datei `KI-Zentrale-Setup-<Version>.exe` herunterladen.
2. Starten und dem Assistenten folgen.
   Windows zeigt eventuell „Der Computer wurde durch Windows geschützt“ – dann auf **„Weitere Informationen“ → „Trotzdem ausführen“** klicken (die Datei ist nicht mit einem gekauften Zertifikat signiert).
3. Beim ersten Start ein eigenes Profil anlegen – der Einrichtungsassistent hilft beim Rest.

Bereits installierte KI-Zentralen finden neue Versionen von selbst (Einstellungen → Updates).

## Gut zu wissen

- **Privates Projekt.** Nutzung auf eigene Verantwortung, ohne Gewähr und ohne Support.
- Jede Installation ist eigenständig: Deine Daten bleiben auf deinem PC.
- Cloud-KI (z. B. Claude) braucht einen eigenen API-Schlüssel; die Kosten laufen über dein eigenes Konto beim Anbieter.
- Updates sind digital signiert und werden vor der Installation geprüft.
- Hier liegen nur Installationsdateien und Update-Daten – kein Quellcode.
